# RXShare

Self-hosted file sharing. Upload stuff, get links, share them. That's it.

> ⚠️ **Beta** — This is still in active development. Things might break, data might vanish, dragons might appear. Don't run this in production unless you're okay with that. Back up your data.

## Features

- **Drag & drop uploads** with auto-generated thumbnails and previews
- **Public/private sharing** with direct links and short URLs
- **Custom OG embeds** for Discord, Twitter, etc. (title, description, color per user)
- **Admin panel** — manage users, quotas, site settings, theming
- **API tokens** for programmatic uploads (ShareX compatible)
- **User profiles** with custom URL paths
- **2FA / TOTP** support for account security
- **Multiple layouts** — sidebar, header, floating dock
- **Color theming** and background patterns
- **Encryption at rest** — optional AES-256-GCM file encryption
- **SQLite** by default, **MySQL/MariaDB** if you need it
- **Local storage** by default, **S3-compatible** (AWS, R2, MinIO) if you want it

## One-Click Install

One command. Installs Docker if needed, sets everything up, and starts the app.

```bash
curl -fsSL https://raw.githubusercontent.com/RXShare/RXShare/main/install.sh | sudo bash
```

The installer will ask you how to expose RXShare:

| Option | Description |
|--------|-------------|
| **Cloudflare Tunnel** | Zero exposed ports, automatic HTTPS. Needs a [tunnel token](https://one.dash.cloudflare.com). |
| **Local only** | Binds to `127.0.0.1:6910`. Nobody outside your machine can reach it. |
| **Open** | Binds to `0.0.0.0:6910`. Make sure you have a firewall. |

After install, open your browser and go to `/setup` to create your admin account and configure the instance.

## Docker (manual)

If you prefer to handle it yourself:

```bash
git clone https://github.com/RXShare/RXShare.git
cd RXShare
cp .env.example .env        # edit .env with your secrets
docker compose up -d --build
```

For local-only access, change the port binding in `docker-compose.yml`:

```yaml
ports:
  - "127.0.0.1:6910:3000"
```

## Without Docker

Requires Node.js 20+.

```bash
git clone https://github.com/RXShare/RXShare.git
cd RXShare
npm install
npm run build
npm start
```

Open `http://localhost:3000` — the setup wizard handles the rest.

## Configuration

Everything lives in `.env`. The setup wizard writes it for you on first run, or check [`.env.example`](.env.example) for all available options.

Key settings:

| Variable | Default | Description |
|----------|---------|-------------|
| `PORT` | `3000` | Server port |
| `JWT_SECRET` | — | Random secret for auth tokens (auto-generated by installer) |
| `DB_TYPE` | `sqlite` | `sqlite` or `mysql` |
| `STORAGE_TYPE` | `local` | `local` or `s3` |
| `ENCRYPTION_KEY` | — | 64-char hex string for AES-256-GCM encryption at rest |
